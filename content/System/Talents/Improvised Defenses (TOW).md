# Improvised Defenses
**Tier:** 3  
**Activation:** Active-action  
**Ranked:** No  
Your character may use this talent to make an Average ( #GenesysDifficulty #GenesysDifficulty ) Engineering check to attempt to create temporary cover. If the check is successful, the cover provides a ranged defense of 1 and can cover one character for each uncanceled #GenesysSuccess . #GenesysTriumph can be spend to increase defense provided to 2.
