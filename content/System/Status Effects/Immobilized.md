# Immobilized
An immobilized character cannot perform maneuvers (including maneuvers purchased via strain or by spending #GenesysAdvantage ). Most effects that immobilize a character last for a set duration. If a set duration is not specified, immobilization lasts until the end of the character’s next turn. If a character is immobilized multiple times, each instance increases the total duration of the effect by the instance’s specified duration, but may not increase the total duration beyond the scope of the
present encounter.
