# Disoriented
A disoriented character adds #GenesysSetback to all checks they make. Most effects that disorient a character last for a set duration. If a set duration is not specified, disorientation lasts until the end of the character’s next turn. If a character is disoriented multiple times, each instance
increases the total duration of the effect by the instance’s specified duration, but may not increase the total duration beyond the scope of the present encounter.
